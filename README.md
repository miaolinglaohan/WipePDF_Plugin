# WipePDF Acrobat 插件版 (Adobe Acrobat 64-bit 原生增强插件)

基于 **Adobe Acrobat Core API** 原生开发的专业 PDF 顽固水印清理插件，无缝集成到 Acrobat Pro 顶部菜单栏。

---

## 🛠️ 核心功能

### 1. 手动点选删除同款水印（最精准，推荐）
在人工视觉辅助下，点击页面上的水印元素，插件会识别该元素的特征（类型、像素尺寸、页面位置、内容），并**只删除全篇文档中同款的水印对象**，绝不触碰其他内容。
- 支持穿透 **Form XObject / 标记内容 Container**（如 `/Artifact /Subtype /Watermark` 块）内的水印
- 支持图片、矢量路径、文本三种水印类型
- 删除前显示命中元素的完整特征 + 全篇匹配数量预览 + 自动备份原文档
- 整页元素触发高危二次确认，防止误删扫描版背景图

### 2. 一键清除当前文档水印（保守安全）
自动清理高置信度的水印对象：
- **PDF 标准水印标记**（`/Artifact /Subtype /Watermark`，CamScanner 等扫描软件的标准标注）
- **透明/隐形文字**（`RenderMode=3`、`Opacity=0`）
- **URL / 品牌关键词水印文字**（`www.`、`http`、`扫描全能王`、`CamScanner` 等，带字号与 ASCII 守卫，避免误删正文）
- **链接注解**（Link，默认关闭，含目录跳转/外链，可在规则设置中开启）

> ⚠️ **设计原则：宁漏删，不误删。** 一键清除默认只启用高置信规则；几何启发式（底部通栏、图案填充、大覆盖层）默认关闭，需要在【水印清理规则设置】中显式开启，或使用手动点选功能精确删除。

### 3. 框选区域涂白遮盖（专克底图融合水印）
针对已与整页扫描背景图/底图融为一体的边角顽固水印（如“学兔兔”等网址、印章），通过鼠标**按住左键拖动拉框**直接框选水印区域：
- 生成无损矢量纯白遮罩（`PDEPath` DeviceRGB 纯白填充），追加至页面顶层
- **100% 保真**：绝不解压或重压缩底图图像，原书扫描图画质 0 损耗
- 支持自适应全篇文档相同相对坐标批量覆盖，或仅针对当前页遮盖

### 4. 一键清除当前文档元数据
彻底清除 PDF 文档中的隐藏隐私与属性信息（文档正文内容不受任何影响）：
- **XMP 现代元数据**：重置为空标准数据包，清除拍摄设备、地理位置（GPS）、自定义属性等
- **传统 Info 字典**：彻底清空标题、作者、主题、关键词、生成工具（Creator/Producer）、创建/修改时间
- 具备完善的 Catalog `/Metadata` 降级容错机制与 `PDDocNeedsSave` 保存提示保护

### 5. 批量清除 PDF 元数据
面对海量或整套文档归档、分发、对外保密需求，一键批量清空全套文档元数据：
- **多选批量导入**：支持在 Windows 原生文件窗口中一次性选取多个或整个目录的 PDF 文件
- **双轨彻底擦除**：同步擦除传统 Info 字典（标题、作者、制作工具、时间戳等）与现代 XMP 元数据流
- **物理覆写与垃圾回收**：采用 `PDSaveFull | PDSaveCollectGarbage` 进行全文件物理结构重写，彻底清除游离孤立的元数据二进制对象，杜绝增量保存残留漏洞
- **修改前自动独立备份**：每个文件在处理前均会自动快照至 `%TEMP%\WipePDF_Backups\` 专有目录，安全无忧
- **文档正文 0 损耗**：正文图文、排版、矢量字体、注释结构 100% 保持原样，绝不改动文档任何可视内容
- **异常容错与汇总报告**：遇只读/损坏文件自动隔离记录并继续处理下一文件，最终提供详细的成功/失败统计与明细报告

### 6. 批量文档水印清理
多选多个 PDF 文件，逐个执行保守清理并覆盖保存，汇总统计每个文件的清理结果。

### 7. 安全备份文件管理（三位一体生命周期管理）
- **独立专有目录**：备份文件集中存储于 `%TEMP%\WipePDF_Backups\` 独立文件夹，文件名带有人类可读时间戳（如 `WipePDF_backup_20260930_195530_123.pdf`），不再与系统杂乱临时文件混放。
- **一键打开备份文件夹**：点击菜单直接唤起 Windows 文件资源管理器打开备份目录，方便快速核对或取回原件。
- **一键清空历史备份**：智能扫描备份文件数量与总占用 MB，弹窗核对后一键安全清空，并反馈释放的磁盘空间。
- **自动过期轮转淘汰**：每次产生新备份时，后台静默自动清理超过 7 天的历史备份，免人工维护、永不撑爆 C 盘。

### 8. 扫描当前页面水印元素
透视展示当前页面的图元分布：文本/路径/图片元素数、隐形文本数、关键词命中、链接注解数等。

### 9. 规则设置面板
可视化开关一键清除的过滤规则（透明文本、关键词文本、底部通栏、图案填充、链接注解）。

### 10. 安全机制
- **删除前自动备份**：所有修改操作前均将原文档完整备份到 `%TEMP%\WipePDF_Backups\` 专有目录
- **数量预览**：删除前显示全篇将匹配删除的元素数量
- **`PDDocNeedsSave` 标记**：修改后 Acrobat 关闭时提示保存，不会静默覆盖原文件
- **页面即时刷新**：采用 `PDPageNotifyContentsDidChange`，清理后无感重绘

## 🚀 快速安装与使用

### 方式一：一键自动安装（推荐）

在项目根目录下，直接双击运行：
```
一键安装到Acrobat.bat
```
*(系统若弹出管理员 UAC 授权提示，点击“是”即可)*

脚本会自动将编译好的 `WipePDF.api` 部署至：
`C:\Program Files\Adobe\Acrobat DC\Acrobat\plug_ins\WipePDF.api`

### 方式二：手动复制安装

1. 完全关闭 Adobe Acrobat。
2. 将 `build/WipePDF.api` 复制到您的 Acrobat 插件目录（需管理员权限）：
   `C:\Program Files\Adobe\Acrobat DC\Acrobat\plug_ins\`
3. 重新启动 Acrobat，顶部菜单栏出现【水印清理 (WipePDF)】即安装成功。

---

## 🎯 在 Acrobat 中使用 WipePDF

1. 打开 **Adobe Acrobat Pro**。
2. 打开任意带有顽固水印的 PDF 文档。
3. 顶部菜单栏点击 **【水印清理 (WipePDF)】**：
   - **一键清除当前文档水印**：保守清理全文高置信水印对象。
   - **点选同款水印清理...**：点击水印 → 确认特征 → 精准删除全篇同款。
   - **框选涂白遮盖 (底图融合水印)...**：拖拽选框 → 无损矢量白块覆盖。
   - **一键清除当前文档元数据**：重置 XMP + 清空 Info 字典。
   - **打开安全备份文件夹...**：快速查看恢复原件。
   - **一键清空历史备份文件...**：释放磁盘空间。
   - **批量文档水印清理...**：多文件批量清理。
   - **水印清理规则设置...**：按需开启/关闭过滤规则。
4. 满意后按 `Ctrl + S` 保存文档（关闭时 Acrobat 会提示保存）。
