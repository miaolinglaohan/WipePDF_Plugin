# WipePDF Acrobat 插件版 (Adobe Acrobat 64-bit 原生增强插件)

基于 **Adobe Acrobat Core API** 原生开发的专业 PDF 顽固水印清理插件，无缝集成到 Acrobat Pro 顶部菜单栏。

---

## 🛠️ 核心功能

### 1. 手动点选删除同款水印（最精准，推荐）
在人工视觉辅助下，点击页面上的水印元素，插件会识别该元素的特征（类型、像素尺寸、页面位置、内容），并**只删除全篇文档中同款的水印对象**，绝不触碰其他内容。
- 支持穿透 **Form XObject / 标记内容 Container**（如 `/Artifact /Subtype /Watermark` 块）内的水印
- 支持图片、矢量路径、文本三种水印类型
- 删除前显示命中元素的完整特征 + 全篇匹配数量预览 + 自动备份原文档
- 整页元素触发高危二次确认，防止误删扫描版背景图

### 2. 一键清除当前文档水印（保守安全）
自动清理高置信度的水印对象：
- **PDF 标准水印标记**（`/Artifact /Subtype /Watermark`，CamScanner 等扫描软件的标准标注）
- **透明/隐形文字**（`RenderMode=3`、`Opacity=0`）
- **URL / 品牌关键词水印文字**（`www.`、`http`、`扫描全能王`、`CamScanner` 等，带字号与 ASCII 守卫，避免误删正文）
- **推广链接注解**（Link）

> ⚠️ **设计原则：宁漏删，不误删。** 一键清除默认只启用高置信规则；几何启发式（底部通栏、图案填充、大覆盖层）默认关闭，需要在【水印清理规则设置】中显式开启，或使用手动点选功能精确删除。

### 3. 批量文档水印清理
多选多个 PDF 文件，逐个执行保守清理并覆盖保存，汇总统计每个文件的清理结果。

### 4. 扫描当前页面水印元素
透视展示当前页面的图元分布：文本/路径/图片元素数、隐形文本数、关键词命中、链接注解数等。

### 5. 规则设置面板
可视化开关一键清除的过滤规则（透明文本、关键词文本、底部通栏、图案填充、链接注解）。

### 6. 安全机制
- **删除前自动备份**：操作前将原文档完整备份到 `%TEMP%\WipePDF_backup_*.pdf`
- **数量预览**：删除前显示全篇将匹配删除的元素数量
- **`PDDocNeedsSave` 标记**：修改后 Acrobat 关闭时提示保存，不会静默覆盖原文件
- **页面即时刷新**：采用 `PDPageNotifyContentsDidChange`，清理后无感重绘

## 🚀 快速安装与使用

### 方式一：一键自动安装（推荐）

在项目根目录下，直接双击运行：
```
一键安装到Acrobat.bat
```
*(系统若弹出管理员 UAC 授权提示，点击“是”即可)*

脚本会自动将编译好的 `WipePDF.api` 部署至：
`C:\Program Files\Adobe\Acrobat DC\Acrobat\plug_ins\WipePDF.api`

### 方式二：手动复制安装

1. 完全关闭 Adobe Acrobat。
2. 将 `build/WipePDF.api` 复制到您的 Acrobat 插件目录（需管理员权限）：
   `C:\Program Files\Adobe\Acrobat DC\Acrobat\plug_ins\`
3. 重新启动 Acrobat，顶部菜单栏出现【水印清理 (WipePDF)】即安装成功。

---

## 🎯 在 Acrobat 中使用 WipePDF

1. 打开 **Adobe Acrobat Pro**。
2. 打开任意带有顽固水印的 PDF 文档。
3. 顶部菜单栏点击 **【水印清理 (WipePDF)】**：
   - **一键清除当前文档水印**：保守清理全文高置信水印对象。
   - **手动点选同款水印...**：点击水印 → 确认特征 → 精准删除全篇同款。
   - **扫描当前页面水印元素...**：透视展示当前页面图元分布。
   - **批量文档水印清理...**：多文件批量清理。
   - **水印清理规则设置...**：按需开启/关闭过滤规则。
4. 满意后按 `Ctrl + S` 保存文档（关闭时 Acrobat 会提示保存）。
